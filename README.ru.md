# Process Launcher

Лёгкий лаунчер для Windows и macOS: добавляй программы один раз и
запускай их в один клик, по горячей клавише или целыми наборами.
Приложение следит за запущенными процессами, умеет перезапускать
упавшие и живёт в системном трее.

*(English version: [README.md](README.md))*

---

## Установка

**Windows.** Скачай свежий `ProcessLauncher-Setup-x.y.exe` со страницы
[релизов](https://github.com/Ruha24/ProcessLauncher/releases),
запусти и следуй мастеру. Установщик создаст ярлык в меню Пуск
(и по желанию на рабочем столе). Права администратора не нужны.

**macOS.** Скачай `ProcessLauncher.dmg`, открой его и перетащи
приложение в папку Applications. При первом запуске, если система
покажет предупреждение о неизвестном разработчике — правый клик
по приложению → «Открыть».

## Как пользоваться

Слева в окне — боковая панель: сверху профили, ниже разделы Schedule,
Startup, Log и Settings.

**Добавить программу.** Нажми «Add…» и выбери, что добавить:

- **Program or script** — .exe или скрипт (.bat, .cmd, .ps1; на macOS
  .sh). Скрипты запускаются и отслеживаются так же, как программы.
- **Folder** — папка; по клику она открывается в Проводнике (Finder).
- **Link** — сайт или ссылка приложения (`https://…`, `steam://…`);
  открывается в своём приложении.

Можно и просто перетащить в окно файл, папку или ярлык .lnk/.url.
Ярлыки распознаются автоматически — добавится сама программа (или
сайт), а не ярлык; у ярлыков игр Steam берутся их название и иконка.
Папки и ссылки только открываются: статуса «запущено» у них нет,
поэтому вместо «Start» у них кнопка «Open». Иконка для ссылки находится
сама: для сайта — его значок, для игры Steam (`steam://rungameid/…`) —
иконка из кеша Steam.

**Запуск и остановка.** Кнопка «Start» рядом с программой или двойной
клик по строке. Кнопка «⋯» (или правый клик) открывает остальное:

- **Rename…** — своё название вместо имени файла (пустое поле
  возвращает имя файла);
- **Change icon…** — своя иконка: картинка (.png, .jpg, .ico) или
  иконка любого .exe; у ссылок есть ещё «Get icon from link»;
- **Hotkey…**, **Launch arguments…**, заметка;
- **Start delay…** — через сколько секунд после старта профиля
  запускать программу (например, сначала VPN, клиент через 5 секунд).
  Действует только при запуске всего профиля;
- **Working folder…** — папка, в которой запускается программа (по
  умолчанию — папка, где она лежит);
- **Restart if it stops** — авто-перезапуск;
- **Run as administrator** (Windows) — запуск через окно UAC; такие
  программы помечены значком «Admin» и тоже останавливаются кнопкой
  «Stop»;
- перенос в другой профиль, открыть папку, копировать путь, удалить из
  списка.

**Трей.** Правый клик по значку в трее открывает меню со всеми
профилями: в каждом — «Start all», «Stop all» и сами программы. Клик по
программе запускает её или останавливает; запущенные отмечены зелёной
точкой на иконке, рядом с профилем — сколько программ запущено.

**Горячие клавиши.** Программе или целому профилю можно назначить
глобальную горячую клавишу — она работает, даже когда лаунчер свёрнут.
На macOS модификаторы — Cmd, Ctrl, Option и Shift.

**Профили.** Группируй программы (например «Работа» и «Игры»). Число
рядом с профилем показывает, сколько его программ запущено. «Start
all» запускает весь профиль; кнопка «⋯» рядом переименовывает профиль,
задаёт цвет, иконку и горячую клавишу, создаёт ярлык на рабочем столе
(Windows) или удаляет профиль.

**Расписание.** Запуск или остановка профиля или отдельной программы
в заданное время: один раз или по выбранным дням недели (например,
запускать рабочие программы по будням в 9:00 и закрывать игры в 23:00).
Если компьютер в нужную минуту спал, правило сработает, когда он
проснётся, — в пределах 5 минут.

**Слежение за падениями.** Включи у программы «Restart if it stops» —
если она завершится, лаунчер поднимет её снова. Всё, что остановилось
или дало ошибку, видно на странице Log.

**Автозагрузка.** Раздел Startup показывает, что стартует вместе с
системой, и позволяет выключать и удалять записи. В Windows это тот же
список, что в Диспетчере задач; в macOS — агенты запуска.

**Настройки.** Тёмная/светлая тема, запуск лаунчера вместе с системой,
профиль, который стартует при открытии лаунчера, поведение при закрытии
(оставаться в трее или выходить), закрывать ли запущенные программы
при выходе из лаунчера, тайминги, экспорт и импорт всего в файл —
удобно переносить на другой компьютер.

**Командная строка.** Лаунчером можно управлять из ярлыков и скриптов:

```
ProcessLauncher --profile "Работа"         запустить профиль
ProcessLauncher --stop-profile "Игры"      остановить профиль
ProcessLauncher --start "Telegram"         запустить программу по имени
ProcessLauncher --stop "Telegram"          остановить программу
ProcessLauncher --hidden                   запуститься сразу в трей
ProcessLauncher --show                     показать окно
```

Если лаунчер уже работает, команда передаётся ему. С командами окно не
открывается — всё происходит в фоне; если профиль или программа не
найдены, придёт уведомление. Ярлык из меню профиля («Create desktop
shortcut») использует как раз `--profile`.

## Возможности по платформам

| Функция                     | Windows | macOS |
|-----------------------------|:-------:|:-----:|
| Запуск/остановка программ   | да      | да    |
| Отслеживание дерева процессов | да    | да    |
| Профили, заметки, оформление | да     | да    |
| Системный трей              | да      | да    |
| Автозапуск с системой       | да      | да    |
| Журнал событий, обновления  | да      | да    |
| Глобальные горячие клавиши  | да      | да    |
| Менеджер автозагрузки       | да      | да*   |
| Меню трея с программами     | да      | да    |
| Скрипты                     | .bat .cmd .ps1 | .sh |
| Папки и ссылки              | да      | да    |
| Запуск от администратора    | да      | нет   |
| Командная строка            | да      | да    |
| Ярлык профиля на рабочем столе | да   | нет   |
| Распознавание .lnk / .url   | да      | нет   |

\* На macOS менеджер показывает агенты запуска из
`~/Library/LaunchAgents`; «Объекты входа» из Системных настроек в список
не попадают.

Ярлыки .lnk и .url — формат Windows, поэтому их распознавание есть
только там.

---

## Обновления

Приложение само проверяет наличие новой версии при запуске и, если
она вышла, предлагает открыть страницу загрузки. Установка остаётся
за тобой — приложение только подсказывает.
