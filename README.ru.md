# Process Launcher

Лёгкий лаунчер для Windows и macOS: добавляй программы один раз и
запускай их в один клик, по горячей клавише или целыми наборами.
Приложение следит за запущенными процессами, умеет перезапускать
упавшие и живёт в системном трее.

*(English version: [README.md](README.md))*

---

## Установка

**Windows.** Скачай свежий `ProcessLauncher-Setup-x.y.exe` со страницы
[релизов](https://github.com/Ruha24/ProcessLauncher/releases),
запусти и следуй мастеру. Установщик создаст ярлык в меню Пуск
(и по желанию на рабочем столе). Права администратора не нужны.

**macOS.** Скачай `ProcessLauncher.dmg`, открой его и перетащи
приложение в папку Applications. При первом запуске, если система
покажет предупреждение о неизвестном разработчике — правый клик
по приложению → «Открыть».

## Как пользоваться

Слева в окне — боковая панель: сверху профили, ниже разделы Schedule,
Startup, Log и Settings.

**Добавить программу.** Нажми «Add program» и выбери .exe, либо просто
перетащи файл (или ярлык .lnk/.url) в окно. Ярлыки распознаются
автоматически — добавится сама программа, а не ярлык.

**Запуск и остановка.** Кнопка «Start» рядом с программой или двойной
клик по строке. Кнопка «⋯» (или правый клик) открывает остальное:
перезапуск, горячая клавиша, аргументы запуска, заметка,
авто-перезапуск, перенос в другой профиль, открыть папку, копировать
путь, удалить из списка.

**Горячие клавиши.** Программе или целому профилю можно назначить
глобальную горячую клавишу — она работает, даже когда лаунчер свёрнут.
На macOS модификаторы — Cmd, Ctrl, Option и Shift.

**Профили.** Группируй программы (например «Работа» и «Игры»). Число
рядом с профилем показывает, сколько его программ запущено. «Start
all» запускает весь профиль; кнопка «⋯» рядом переименовывает профиль,
задаёт цвет, иконку и горячую клавишу или удаляет его.

**Расписание.** Запуск профиля или отдельной программы в заданное
время — один раз или каждый день.

**Слежение за падениями.** Включи у программы «Restart if it stops» —
если она завершится, лаунчер поднимет её снова. Всё, что остановилось
или дало ошибку, видно на странице Log.

**Автозагрузка.** Раздел Startup показывает, что стартует вместе с
системой, и позволяет выключать и удалять записи. В Windows это тот же
список, что в Диспетчере задач; в macOS — агенты запуска.

**Настройки.** Тёмная/светлая тема, запуск лаунчера вместе с системой,
профиль, который стартует при открытии лаунчера, поведение при закрытии
(оставаться в трее или выходить), закрывать ли запущенные программы
при выходе из лаунчера, тайминги, экспорт и импорт всего в файл —
удобно переносить на другой компьютер.

## Возможности по платформам

| Функция                     | Windows | macOS |
|-----------------------------|:-------:|:-----:|
| Запуск/остановка программ   | да      | да    |
| Отслеживание дерева процессов | да    | да    |
| Профили, заметки, оформление | да     | да    |
| Системный трей              | да      | да    |
| Автозапуск с системой       | да      | да    |
| Журнал событий, обновления  | да      | да    |
| Глобальные горячие клавиши  | да      | да    |
| Менеджер автозагрузки       | да      | да*   |
| Распознавание .lnk / .url   | да      | нет   |

\* На macOS менеджер показывает агенты запуска из
`~/Library/LaunchAgents`; «Объекты входа» из Системных настроек в список
не попадают.

Ярлыки .lnk и .url — формат Windows, поэтому их распознавание есть
только там.

---

## Обновления

Приложение само проверяет наличие новой версии при запуске и, если
она вышла, предлагает открыть страницу загрузки. Установка остаётся
за тобой — приложение только подсказывает.
