# Process Launcher

Лёгкий лаунчер для Windows и macOS: добавляй программы один раз и
запускай их в один клик, по горячей клавише или целыми наборами.
Приложение следит за запущенными процессами, умеет перезапускать
упавшие и живёт в системном трее.

*(English version: [README.md](README.md))*

---

## Установка

**Windows.** Скачай свежий `ProcessLauncher-Setup-x.y.exe` со страницы
[релизов](https://github.com/Ruha24/ProcessLauncher/releases),
запусти и следуй мастеру. Установщик создаст ярлык в меню Пуск
(и по желанию на рабочем столе). Права администратора не нужны.

**macOS.** Скачай `ProcessLauncher.dmg`, открой его и перетащи
приложение в папку Applications. При первом запуске, если система
покажет предупреждение о неизвестном разработчике — правый клик
по приложению → «Открыть».

## Как пользоваться

Интерфейс есть на русском и английском. По умолчанию язык берётся из
системы, сменить его можно в «Настройки → Язык». Ниже названия кнопок
даны по-русски.

Слева в окне — боковая панель: сверху профили, ниже разделы
«Расписание», «Автозагрузка», «Статистика», «Журнал» и «Настройки».

**Добавить программу.** Нажми «Добавить…» и выбери, что добавить:

- **Программу или скрипт** — .exe или скрипт (.bat, .cmd, .ps1; на
  macOS .sh). Скрипты запускаются и отслеживаются так же, как программы.
- **Папку** — по клику она открывается в Проводнике (Finder).
- **Ссылку** — сайт или ссылка приложения (`https://…`, `steam://…`);
  открывается в своём приложении.

Можно и просто перетащить в окно файл, папку или ярлык .lnk/.url.
Ярлыки распознаются автоматически — добавится сама программа (или
сайт), а не ярлык; у ярлыков игр Steam берутся их название и иконка.
Папки и ссылки только открываются: статуса «работает» у них нет,
поэтому вместо «Запустить» у них кнопка «Открыть». Иконка для ссылки
находится сама: для сайта — его значок, для игры Steam
(`steam://rungameid/…`) — иконка из кеша Steam.

**Запуск и остановка.** Кнопка «Запустить» рядом с программой или
двойной клик по строке. У запущенной программы видно, сколько она
работает и сколько занимает памяти и процессора — вместе с дочерними
процессами. Кнопка «⋯» (или правый клик) открывает остальное:

- **Переименовать…** — своё название вместо имени файла (пустое поле
  возвращает имя файла);
- **Сменить иконку…** — своя иконка: картинка (.png, .jpg, .ico) или
  иконка любого .exe; у ссылок есть ещё «Взять иконку по ссылке»;
- **Горячая клавиша…**, **Аргументы запуска…**, заметка;
- **Задержка запуска…** — через сколько секунд после старта профиля
  запускать программу (например, сначала VPN, клиент через 5 секунд).
  Действует только при запуске всего профиля;
- **Рабочая папка…** — папка, в которой запускается программа (по
  умолчанию — папка, где она лежит);
- **Окно…** (Windows) — открывать окно программы как обычно, свёрнутым
  или развёрнутым на весь экран. Некоторые программы сами выбирают
  размер окна и эту настройку не слушают;
- **Переменные окружения…** — свои строки `ИМЯ=значение` только для этой
  программы; `%ИМЯ%` подставляет текущее значение
  (`JAVA_OPTS=%JAVA_OPTS% -Xmx2g`), пустое значение убирает переменную;
- **Перезапускать, если закроется** — авто-перезапуск;
- **Запускать от администратора** (Windows) — запуск через окно UAC;
  такие программы помечены значком «Админ» и тоже останавливаются
  кнопкой «Остановить»;
- **Дублировать** — копия программы сразу под ней, например чтобы
  запускать её с другими аргументами или держать в другом профиле;
- перенос в другой профиль, открыть папку, копировать путь, убрать из
  списка.

**Уже запущенные программы.** Если программа из списка уже открыта —
ты запустил её сам или она работала до лаунчера, — через пару секунд её
строка покажет «Работает», а «Запустить» не откроет вторую копию. Время
работы считается от её настоящего запуска. Скрипты так распознать
нельзя.

**Быстрый поиск.** Нажми Ctrl+Alt+Space в любом окне (сменить или
выключить — «Настройки → Быстрый поиск»). Поверх всех окон откроется
поиск: набери несколько букв названия программы или профиля (из любого
профиля) и нажми Enter, чтобы запустить, или Ctrl+Enter (Cmd+Enter на
macOS), чтобы остановить. Набранное не в той раскладке («ntktuhfv»)
тоже находится.

**Статистика.** Раздел «Статистика» показывает, сколько работала каждая
программа сегодня, за последние 7 дней и за всё время, — больше всего
сверху. Время считается, пока программа работает, в том числе если она
запущена не через лаунчер.

**Порядок.** Наведи мышь на строку и перетащи её за ручку слева (шесть
точек) выше или ниже. Профиль запускает программы сверху вниз.

**Трей.** Правый клик по значку в трее открывает меню со всеми
профилями: в каждом — «Запустить все», «Остановить все» и сами
программы. Клик по программе запускает её или останавливает; запущенные
отмечены зелёной точкой на иконке, рядом с профилем — сколько программ
запущено.

**Горячие клавиши.** Программе или целому профилю можно назначить
глобальную горячую клавишу — она работает, даже когда лаунчер свёрнут.
На macOS модификаторы — Cmd, Ctrl, Option и Shift.

**Профили.** Группируй программы (например «Работа» и «Игры»). Число
рядом с профилем показывает, сколько его программ запущено. «Запустить
все» запускает весь профиль; кнопка «⋯» рядом переименовывает профиль,
задаёт цвет, иконку и горячую клавишу, создаёт ярлык на рабочем столе
(Windows) или удаляет профиль.

**Расписание.** Запуск или остановка профиля или отдельной программы
в заданное время: один раз или по выбранным дням недели (например,
запускать рабочие программы по будням в 9:00 и закрывать игры в 23:00).
Если компьютер в нужную минуту спал, правило сработает, когда он
проснётся, — в пределах 5 минут.

**Слежение за падениями.** Включи у программы «Перезапускать, если
закроется» — если она завершится, лаунчер поднимет её снова. Всё, что
остановилось или дало ошибку, видно в «Журнале».

**Автозагрузка.** Раздел «Автозагрузка» показывает, что стартует вместе
с системой, и позволяет выключать и удалять записи. В Windows это тот же
список, что в Диспетчере задач; в macOS — агенты запуска.

**Настройки.** Тёмная/светлая тема, язык интерфейса, клавиша быстрого
поиска, запуск лаунчера вместе с системой, профиль, который стартует при открытии лаунчера,
поведение при закрытии (оставаться в трее или выходить), закрывать ли
запущенные программы при выходе из лаунчера, тайминги, экспорт и импорт
всего в файл — удобно переносить на другой компьютер.

**Командная строка.** Лаунчером можно управлять из ярлыков и скриптов:

```
ProcessLauncher --profile "Работа"         запустить профиль
ProcessLauncher --stop-profile "Игры"      остановить профиль
ProcessLauncher --start "Telegram"         запустить программу по имени
ProcessLauncher --stop "Telegram"          остановить программу
ProcessLauncher --hidden                   запуститься сразу в трей
ProcessLauncher --show                     показать окно
```

Если лаунчер уже работает, команда передаётся ему. С командами окно не
открывается — всё происходит в фоне; если профиль или программа не
найдены, придёт уведомление. Ярлык из меню профиля («Ярлык на рабочем
столе») использует как раз `--profile`.

## Возможности по платформам

| Функция                     | Windows | macOS |
|-----------------------------|:-------:|:-----:|
| Запуск/остановка программ   | да      | да    |
| Отслеживание дерева процессов | да    | да    |
| Профили, заметки, оформление | да     | да    |
| Системный трей              | да      | да    |
| Автозапуск с системой       | да      | да    |
| Журнал событий, обновления  | да      | да    |
| Глобальные горячие клавиши  | да      | да    |
| Менеджер автозагрузки       | да      | да*   |
| Меню трея с программами     | да      | да    |
| Скрипты                     | .bat .cmd .ps1 | .sh |
| Папки и ссылки              | да      | да    |
| Запуск от администратора    | да      | нет   |
| Командная строка            | да      | да    |
| Ярлык профиля на рабочем столе | да   | нет   |
| Распознавание .lnk / .url   | да      | нет   |
| Память и CPU программ       | да      | да    |
| Русский и английский интерфейс | да   | да    |
| Подхват уже запущенных программ | да  | да    |
| Быстрый поиск по клавише    | да      | да    |
| Статистика времени          | да      | да    |
| Переменные окружения        | да      | да    |
| Как открывать окно          | да      | нет   |

\* На macOS менеджер показывает агенты запуска из
`~/Library/LaunchAgents`; «Объекты входа» из Системных настроек в список
не попадают.

Ярлыки .lnk и .url — формат Windows, поэтому их распознавание есть
только там.

## Обновления

Приложение само проверяет наличие новой версии при запуске и, если
она вышла, предлагает открыть страницу загрузки. Установка остаётся
за тобой — приложение только подсказывает.
